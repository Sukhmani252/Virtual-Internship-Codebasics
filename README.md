## Virtual Internship - AtliQ Technologies
This repository contains all the tasks completed as a virtual intern at AtliQ Technologies.

### WEEK 1: Survey Data Analysis (Excel)

#### Task 1: Data Cleaning
- Checking and handling missing or inconsistent data.
- Standardizing column names across datasets.
- Identifying and removing duplicate records.
- Validating respondent details such as age and standardizing names to title case.
  
#### Task 2: Ad Hoc Analysis

Analyze the cleaned data in Excel to answer the following:

**Demographic Insights:**
- What is the **distribution of respondents across Tier 1 and Tier 2 cities**?
- What is the **gender distribution by age group**?
- Which **age group has the highest number of respondents**?
  
**Brand & Experience Analysis:**
- Which brand has the **highest average taste experience rating**?
- Which purchase locations have the **highest and lowest average taste experience ratings**?
- Which **brand** is **most preferred among respondents aged 19–30**?
- What is the **average taste experience rating across all brands**?

#### Task 3: Python Automation

Consolidate monthly revenue data from the provided **month-wise** CSV files and **automate** its import into a **MySQL database using Python**.

- Created a **Python script** to read and consolidate the month-wise revenue files and loaded the combined data into a structured MySQL table.
- Tested the script with multiple monthly files to ensure accurate data import.

#### Task 4: Kanban Methodology Training

Completed the **Kanban training series** covering the core principles of Kanban, including **visualizing work, limiting work-in-progress (WIP), managing workflow, and optimizing task flow** to improve productivity and efficiency in software development.
